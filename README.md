# 🤖 AI 교육 현장용 수강생 질문 답변 자동 생성 시스템 (Local-First AI Assistant)

> 클라우드 API 비용 0원, 데이터 유출 우려 0% — 100% 로컬 온프레미스 환경에서 수강생의 다양한 질문에 즉시 대응하고 모범 답변을 자가 학습·축적하는 지능형 교육 행정 업무 자동화 프로덕트입니다.

💡 1. Why We Built This? (개발 배경 및 기획 의도)
AI 교육 현장에서 강사로 활동하거나 교육 운영을 하다 보면, 수강생들로부터 매일 수십 개씩 비슷한 맥락의 기술 질문(코드 에러, 개념 이해, 환경 설정 등)을 받게 됩니다.

- 기존의 한계: 매번 반복되는 답변을 타이핑하거나 과거에 답했던 내용을 일일이 찾아보는 데 상당한 시간이 소요되어, 교육의 본질인 멘토링과 심화 코칭에 집중하기 어려웠습니다.
- 해결 목표: "내가 편하려고 만든다"는 실무적 관점에서 출발하여, AI가 초안 답변과 투 트랙 옵션을 구조화해주고, 의미 기반 시맨틱 캐시(Semantic Cache)를 통해 한 번 답변한 내용은 초고속으로 재활용할 수 있는 완전 자동화 툴을 직접 구축하게 되었습니다.

🛠️ 2. 핵심 기술 스택 (Tech Stack)
- Language & Framework: Python, Streamlit
- AI Orchestration & LLM: LangChain, LangGraph, Ollama (gemma4:12b 전용 생성 모델, mxbai-embed-large 임베딩 모델)
- Database & Caching: ChromaDB Semantic Cache (Full CRUD 및 영구 아카이브 지원)
- Infrastructure: 100% Local-First 온프레미스 구동 (RTX 5060 Ti + 64GB RAM 최적화)

🚀 3. 주요 기능 및 아키텍처 특징
- 지능형 시맨틱 캐시 (Semantic Cache):
  * mxbai-embed-large 모델을 통한 실시간 문장 벡터화를 적용하여, 토씨나 문장이 달라도 의미가 유사한 질문이라면 과거 모범 답변을 캐싱하여 기존 40~70초 소요되던 추론 시간을 2~7초 이내로 획기적으로 단축했습니다.
- 휴먼 인 더 루프 (Human-in-the-Loop) 샌딩:
  * AI가 생성한 초안과 맞춤형 옵션을 구조화하여 제공하며, 원클릭 복사 버튼을 통해 마우스 드래그 없이 강사가 즉시 수강생에게 답변을 샌딩할 수 있도록 UX를 최적화했습니다.
- ChromaDB 기반 상담 아카이브 (Full CRUD):
  * 생성된 모든 질의응답 기록이 영구 저장되며, 사이드바를 통해 자유로운 조회, 내용 수정, 삭제 및 st.rerun 기반의 실시간 상태 동기화가 가능합니다.
- 100% 온프레미스 보안 및 자원 최적화:
  * 외부 클라우드 API 의존성을 완전히 배제하여 데이터 유출 제로(Zero-Data Leakage)를 달성했습니다.
  * keep_alive="5m" 설정을 통해 첫 로딩 후 VRAM 상주 및 콜드 스타트를 방지하여 응답 속도를 극대화했습니다.
